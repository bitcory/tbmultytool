# 쇼핑쇼츠 대본 생성 지침

쿠팡 상품 → 숏폼(9:16) 대본을 생성할 때 LLM(ChatGPT 확장 / API)에 보내는 프롬프트 구성.
코드 위치: `src/renderer/pages/ShoppingShorts.tsx` → `genScript()`

---

## 1. 입력(동적 변수)

| 변수 | 출처 | 비고 |
|------|------|------|
| `상품명` | 쿠팡 분석 / 수동 | 필수 |
| `가격` / `할인율` | 쿠팡 분석 / 수동 | 있으면 "가격 N원 (M% 할인)" |
| `핵심 특징` | 사용자 입력 | 비우면 상품명·후기 기반 추론 |
| `실사용 후기` | 쿠팡 상품평 | 텍스트 있는 후기 **최대 5개** (평점·제목·본문 220자) |
| `속성 만족도` | 쿠팡 | 예: 내구성 아주만족 67%, 전송속도 100% |
| `톤` | UI 토글 | 활기참 / 정보형 / 후킹형 |
| `길이` | UI 토글 | 20초(3씬) / 30초(4씬) / 45초(6씬) |
| `인물 표현` | UI 토글 | 제품만 / 손·사용컷(얼굴X) / 자유 |

---

## 2. 기본 프롬프트 (topic)

```
쿠팡 제품 홍보용 {길이}초 세로 숏폼. 상품: "{상품명}". 가격 {가격}원 ({할인}% 할인).
핵심 특징: {핵심특징 or "(특징 미입력 — 상품명/후기 기반으로 매력 포인트를 추론)"}.

실사용 후기:
1. ({별점}점) {제목} — {본문 220자}
2. ...
(최대 5개)

속성 만족도: {라벨 값(퍼센트), ...}

위 실사용 후기에서 자주 언급되는 장점을 근거로, {톤} 톤으로 시청자의 구매욕을 자극하고
마지막에 "지금 링크 확인" CTA로 마무리. 후기 내용을 과장 없이 자연스럽게 녹여라.
```

---

## 3. 이미지 프롬프트 규칙 (항상 첨부)

```
[이미지 프롬프트 규칙 — 매우 중요]
- 모든 imagePrompt 는 photorealistic product photography(실사 제품 사진), AI 티가 전혀 안 나게 자연스럽게.
- 실제 제품 이미지를 참조로 합성하므로 제품의 외형/색상/형태를 바꾸지 말 것(keep the exact product).
- 제품이 단 하나의 주인공(single hero product, centered): 제품과 어울리는 깔끔하고 보완적인
  배경/표면(complementary clean background & surface)으로 제품이 돋보이게, 얕은 심도/은은한 조명.
- 주변에 관련 없는 다른 제품·소품·잡동사니 금지(no other unrelated products, no clutter).
- 이미지/제품 위에 어떤 글자도 금지: no text, no captions, no labels, no logos, no watermark, no UI overlay.
- (인물 표현 모드에 따라)
   · 제품만   : 사람/얼굴/손 금지 (no people, no human, no face, no hands)
   · 손·사용컷: 얼굴 금지(no visible face, no recognizable person) + 손·POV·라이프스타일 허용
   · 자유     : 자연스러운 인물 연출 허용, 과한 클로즈업 얼굴 지양
- 9:16 세로 구도(vertical 9:16 composition).
```

---

## 4. 모션(영상) 규칙 — motionPrompt

```
제품을 고정·중앙 유지한 채 카메라가 제품 주변을 천천히 도는 오빗
(slow cinematic orbit/arc around the product, product stays fixed and centered),
부드럽게, 컷 없이, 일관된 180도 법칙(consistent 180-degree rule, camera stays on one side of the axis),
제품 형태/외형 유지. 첫 씬은 특히 이 오빗으로.
```

---

## 5. 출력 형식 (필수)

```
정확히 {씬수}개 씬. 각 씬 = (1) 한국어 나레이션, (2) 영어 imagePrompt, (3) 영어 motionPrompt
반드시 아래 JSON만 ```json 코드블록으로 출력 (설명·인사말 금지):

{"title": "영상제목", "scenes": [
  {"narration": "나레이션", "imagePrompt": "english image prompt", "motionPrompt": "english motion prompt"}
]}
```
